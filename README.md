# GstarCAD Practice Drawings & Exercises

Free practice drawings and step-by-step exercises for learning CAD drafting with [GstarCAD](https://www.gstarcad.net). Perfect for beginners and students who want to build real drafting skills.

## Exercise levels

- **Beginner** – lines, circles, rectangles, basic dimensions
- **Intermediate** – layers, blocks, hatches, plotting
- **Advanced** – 3D modeling, layouts, attribute blocks

## What you will learn

- Precision drawing with coordinates and object snaps
- Organizing drawings with layers and templates
- Reusing content with blocks and external references
- Producing clean, print-ready layouts

## How to practice

1. Get [GstarCAD free trial](https://www.gstarcad.net/download)
2. Open an exercise file and try to reproduce it from the instructions
3. Compare with the reference solution and check the [tutorials](https://www.gstarcad.net/cad/) when stuck
